# Origen y adaptación

La colección parte de skills utilizadas en un proyecto de Trabajo de Diploma
y se adapta para compartirlas entre estudiantes con productos y stacks distintos.

## Adaptaciones para uso general

- El contexto del sistema se declara por proyecto, en lugar de presuponer su
  nombre, tecnología, capas o base de datos.
- El documento y la carpeta Drive se proporcionan en cada proyecto/sesión.
- La numeración de requisitos se contrasta con la consigna de cada comisión.
- La generación de especificaciones Word y la Carpeta Modelo completa son
  recursos externos opcionales, no dependencias incluidas en esta colección.
- Las herramientas locales de publicación se pueden probar sin conexión a Google.

## Referencias y atribución

- [PlantUML](https://plantuml.com/): lenguaje y renderizador externo. El JAR
  no está incluido. Consultar su sitio para licencias y requisitos.
- [Graphviz](https://graphviz.org/): motor de diagramación externo.
- `tp-delivery-standards/embedded-skills/plantuml/` contiene una skill y
  recursos preexistentes adaptados al flujo de TD. Se conservan sus referencias
  y ejemplos; no se atribuye aquí autoría exclusiva sobre ese material.

Este archivo documenta procedencia y alcance; no otorga una licencia nueva
sobre material de terceros. Antes de definir una licencia para todo el
repositorio, su mantenedor debe confirmar las condiciones del material incorporado.
